# PLAYLOG MVP Prototype

모바일 우선 정적 프로토타입입니다. 첨부 기준서의 MVP 범위를 기준으로 홈, 평가 플로우, 공식 선수카드, 개인 회고 카드, 친구 목록을 한 화면 앱 형태로 구성했습니다.

## 실행

브라우저에서 `index.html`을 열면 됩니다.

## 포함된 기준

- OVR 계산: `(공통 평균 * 0.7 + 포지션 평균 * 0.3)` 후 `40 + 경기점수 * 5.5`
- 레이더 6개 압축 스탯: 활동성, 게임 센스, 패스, 볼 컨트롤, 움직임, 멘탈
- 포지션 적응도: 동료가 평가한 포지션 데이터 기준, 평가 없는 포지션은 `-`
- 플레이유형: 대표 포지션과 선택 성향 데이터가 있을 때 표시
- 공식 선수카드와 개인 회고 카드는 UI와 데이터 의미를 분리

## 파일

- `index.html`: 앱 구조
- `styles.css`: 모바일 UI 스타일
- `app.js`: 샘플 데이터, 계산식, 탭/평가 플로우 상호작용
